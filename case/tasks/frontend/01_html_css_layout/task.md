# Модуль 1: HTML и CSS — Практическое задание

## Проект: Лендинг команды чемпионата (TeamLanding)

### Цель

Закрепить семантическую разметку HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`), базовые теги (заголовки, списки, ссылки, изображения, таблицы, формы), атрибуты `class` и `id`, а также основные возможности CSS: селекторы (тег, класс, id, псевдокласс), box model (`margin`, `padding`, `border`), работу с цветом, шрифтами, фоном и простым позиционированием через `display: flex`.

### Техническое задание

Соберите одностраничный лендинг из двух файлов — `index.html` и `style.css`. Использование JavaScript и внешних CSS-фреймворков **запрещено**.

1. **Шапка (`<header>`):**

   - Логотип команды слева.

   - Блок навигации `<nav>` с якорными ссылками на четыре секции страницы: `#about`, `#members`, `#schedule`, `#contact`.

   - Логотип и навигация выстроены в одну строку и прижаты к противоположным краям (`display: flex`, `justify-content: space-between`).

   - При наведении на ссылку навигации меняется цвет (псевдокласс `:hover`).

2. **Секция «О команде» (`id="about"`):**

   - Заголовок второго уровня `<h2>`.

   - Абзац описания не менее 3 предложений.

   - Маркированный список `<ul>` из 4+ технологий стека (Solidity, JavaScript, React, Docker и т. д.).

3. **Секция «Состав» (`id="members"`):**

   - Три карточки участников, каждая обёрнута в `<article class="member-card">`.

   - Внутри карточки: круглый аватар (`border-radius: 50%`, `object-fit: cover`), имя в `<h3>`, роль в `<p class="role">`.

   - Карточки расположены в ряд через `display: flex` с одинаковым `gap`; у каждой карточки есть `border`, `padding` и `border-radius`.

4. **Секция «Расписание» (`id="schedule"`):**

   - Таблица `<table>` с шапкой `<thead>` и телом `<tbody>`.

   - Колонки: `День`, `Модуль`, `Время`. Минимум 4 строки.

   - Границы таблицы схлопнуты (`border-collapse: collapse`), строки шапки имеют отличный от тела фон.

5. **Секция «Контакты» (`id="contact"`):**

   - Форма `<form>` с полями: текстовое имя (`<input type="text">`), почта (`<input type="email">` с атрибутом `required`), выпадающий список `<select>` с направлением подготовки (Solidity / Frontend / DevOps) и многострочное поле `<textarea>`.

   - У каждого поля есть связанный `<label for="...">`, указывающий на `id` поля.

   - Кнопка отправки `<button type="submit">` с собственным фоном и изменением цвета при `:hover`.

6. **Подвал (`<footer>`):**

   - Копирайт и почта, оформленная как ссылка `mailto:`.

   - Текст выровнен по центру, фон отличается от основного.

7. **Общие требования к CSS:**

   - Стили только во внешнем файле `style.css`, подключённом через `<link rel="stylesheet">`.

   - У `body` сброшен `margin`, задано семейство шрифтов и базовый цвет текста.

   - Основной контент ограничен по ширине (`max-width`) и отцентрован (`margin: 0 auto`).

   - Использован минимум один селектор по `id`, один по классу и один групповой селектор (через запятую).

### Критерии приёмки

- Страница открывается локально без ошибок в консоли, кодировка `UTF-8` объявлена в `<head>`.
- Все якорные ссылки в навигации прокручивают к нужным секциям.
- Разметка не содержит «безликих» `<div>` там, где уместен семантический тег.
- Поле почты не даёт отправить форму пустой (срабатывает браузерная валидация `required`).
