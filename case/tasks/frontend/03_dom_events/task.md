# Модуль 3: Связка HTML/CSS и JavaScript — Практическое задание

## Проект: Интерактивный трекер заданий (TaskTracker)

### Цель

Освоить связку разметки и скрипта: подключение `<script>` с атрибутом `defer`, поиск элементов через `document.querySelector` / `querySelectorAll` / `getElementById`, чтение и изменение содержимого (`textContent`, `value`), работу с атрибутами и классами (`classList`), управление стилями из JS, создание и удаление узлов (`createElement`, `append`, `remove`), навигацию по дереву DOM и обработку событий через `addEventListener` (`click`, `submit`, `input`, `change`, `keydown`).

### Техническое задание

Соберите страницу из трёх файлов: `index.html`, `style.css`, `app.js`. Внешние библиотеки не используются.

1. **Разметка (`index.html`):**

   - Шапка с заголовком и счётчиком в формате `Выполнено: 0 из 0` (элемент с `id="counter"`).

   - Форма `id="task-form"` с текстовым полем `id="task-input"`, выпадающим списком `id="task-track"` (Solidity / Frontend / DevOps) и кнопкой `type="submit"`.

   - Пустой список `<ul id="task-list">` — сюда скрипт будет добавлять задания.

   - Панель фильтров: три кнопки с атрибутом `data-filter` со значениями `all`, `active`, `done`.

   - Кнопка `id="clear-done"` — «Удалить выполненные».

   - Скрипт подключён перед `</body>` либо в `<head>` с атрибутом `defer`.

2. **Добавление задания (событие `submit`):**

   - Обработчик вешается через `addEventListener("submit", ...)`, внутри вызывается `event.preventDefault()`, чтобы страница не перезагружалась.

   - Пустая строка (или строка из одних пробелов после `trim()`) не добавляется: поле подсвечивается красной рамкой через `classList.add("error")` и через 1.5 секунды подсветка снимается.

   - Новый элемент списка создаётся через `document.createElement`, а не через `innerHTML` со склейкой строк.

   - Структура элемента: чекбокс `<input type="checkbox">`, `<span class="task-text">` с текстом, `<span class="badge">` с направлением и кнопка удаления `<button class="delete-btn">✕</button>`.

   - Направление записывается в `dataset.track` элемента `<li>`.

   - После добавления поле ввода очищается и получает фокус (`focus()`).

3. **Отметка выполнения (событие `change`):**

   - Переключение чекбокса добавляет/снимает класс `done` у родительского `<li>` (через `classList.toggle` и навигацию `closest("li")`).

   - Класс `done` в CSS зачёркивает текст и приглушает цвет.

4. **Удаление задания (делегирование событий):**

   - Один обработчик `click` вешается на весь `<ul>`, а не на каждую кнопку.

   - Внутри проверяется `event.target.classList.contains("delete-btn")`, затем удаляется ближайший `<li>` через `remove()`.

5. **Фильтрация (событие `click` на панели фильтров):**

   - Кнопка `all` показывает все задания, `active` — только невыполненные, `done` — только выполненные.

   - Скрытие реализуется переключением `style.display` либо класса `hidden`.

   - Активная кнопка фильтра подсвечивается классом `active`, у остальных класс снимается.

6. **Живой поиск (событие `input`):**

   - Добавьте поле `id="search"`. По мере ввода скрываются задания, текст которых не содержит введённую подстроку (сравнение без учёта регистра через `toLowerCase()`).

7. **Счётчик:**

   - Функция `updateCounter()` пересчитывает количество выполненных и общее число заданий и обновляет `textContent` элемента `#counter`.

   - Вызывается после любого изменения: добавления, удаления, переключения чекбокса, очистки.

8. **Очистка выполненных:**

   - Кнопка `#clear-done` удаляет из DOM все `<li class="done">`, найденные через `querySelectorAll`.

9. **Горячая клавиша (событие `keydown`):**

   - Нажатие `Escape` в поле ввода очищает его и снимает фокус (`blur()`).

### Критерии приёмки

- Перезагрузка страницы при отправке формы не происходит.
- Обработчик удаления один на весь список (делегирование), а не по одному на кнопку.
- Задания создаются методами DOM, без вставки HTML-строк.
- Счётчик корректен после любой операции, включая удаление отмеченных заданий.
