# Модуль 2: Основы JavaScript — Практическое задание

## Проект: Зачётная ведомость чемпионата (ScoreBoard)

### Цель

Закрепить объявление переменных (`let`, `const`), примитивные типы данных, проверку типа через `typeof`, приведение типов, арифметические и логические операторы, ветвления (`if / else if / else`, тернарный оператор, `switch`), циклы (`for`, `while`, `for...of`, `for...in`), объявление функций тремя способами, параметры по умолчанию, `return`, области видимости и работу с объектами и массивами объектов.

### Техническое задание

Создайте файл `scoreboard.js`, который запускается в консоли браузера или через Node.js. Никаких DOM-операций — только чистый JavaScript и вывод через `console.log`.

1. **Исходные данные:**

   - Объявите константу `participants` — массив объектов. Каждый объект-участник содержит:

     - `name` (строка) — имя участника;

     - `track` (строка) — направление: `"solidity"`, `"frontend"` или `"devops"`;

     - `scores` (массив чисел) — баллы за выполненные модули (от 0 до 100);

     - `isActive` (булево) — участвует ли в текущем зачёте.

   - В массиве должно быть минимум 5 участников, среди них хотя бы один с `isActive: false` и хотя бы один с пустым массивом `scores`.

2. **Функция `getAverage(scores)` (Function Declaration):**

   - Принимает массив баллов, возвращает среднее арифметическое, округлённое до целого через `Math.round`.

   - Если массив пустой — возвращает `0` (защита от деления на ноль).

   - Сумму считает циклом `for` (не `reduce`).

3. **Функция `getGrade(average)` (Function Expression):**

   - Принимает средний балл и возвращает буквенную оценку через `switch(true)` либо цепочку `if / else if`:

     - 90–100 → `"A"`; 75–89 → `"B"`; 60–74 → `"C"`; меньше 60 → `"F"`.

4. **Стрелочная функция `getTrackLabel(track)`:**

   - Через `switch` возвращает читаемое название направления: `"solidity"` → `"Смарт-контракты"`, `"frontend"` → `"Интерфейсы"`, `"devops"` → `"Инфраструктура"`, любое другое значение → `"Не определено"`.

5. **Функция `buildReport(participant, minScore = 60)`:**

   - Использует параметр по умолчанию `minScore`.

   - Возвращает **объект** со свойствами: `name`, `track` (читаемое название), `average`, `grade`, `passed` (булево — прошёл ли порог; вычислить тернарным оператором).

   - Для формирования полей переиспользует функции из пунктов 2–4.

6. **Формирование отчёта:**

   - Циклом `for...of` пройдите по `participants`, пропустите неактивных через `continue`.

   - Для каждого активного участника вызовите `buildReport` и выведите строку в формате шаблонного литерала:

     `Алина — Смарт-контракты | средний: 87 | оценка: B | зачёт: да`

7. **Статистика (цикл `while`):**

   - Циклом `while` посчитайте, сколько активных участников получили оценку `"A"`.

   - Выведите результат отдельной строкой.

8. **Перебор объекта (цикл `for...in`):**

   - Соберите объект `countByTrack`, где ключ — направление, значение — число участников на нём.

   - Выведите содержимое объекта циклом `for...in` в формате `solidity: 2`.

9. **Демонстрация типов и приведения:**

   - Выведите `typeof` для четырёх разных значений (строка, число, булево, объект).

   - Покажите на примере разницу между `==` и `===` для значений `"5"` и `5`.

   - Перепишите фрагмент с проверкой на `undefined` через оператор нулевого слияния `??` и логическое присваивание `??=`.

### Критерии приёмки

- Код не падает с ошибкой при участнике с пустым массивом `scores`.
- Неактивные участники не попадают в отчёт.
- Использованы все требуемые конструкции: `for`, `while`, `for...of`, `for...in`, `switch`, тернарный оператор, `??`.
- Переменные объявлены через `const` там, где значение не меняется; `var` не используется.
