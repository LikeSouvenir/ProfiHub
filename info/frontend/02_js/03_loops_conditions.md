# Циклы и ветвления

## Ветвление: if / else if / else
```js
let age = 20;

if (age < 18) {
    console.log("Несовершеннолетний");
} else if (age >= 18 && age < 65) {
    console.log("Взрослый");
} else {
    console.log("Пенсионер");
}
```
Условие в `if(...)` приводится к `boolean` — сработает ветка, где условие оказалось `true` (см. правила truthy/falsy из предыдущего конспекта).

## Тернарный оператор
Короткая запись простого `if / else` в одну строку:
```js
let age = 20;
let status = age >= 18 ? "Взрослый" : "Ребёнок";
console.log(status); // "Взрослый"
```
Синтаксис: `условие ? значение_если_true : значение_если_false`.

## switch
Удобен, когда одну и ту же переменную нужно сравнить с несколькими конкретными значениями:
```js
let day = 3;
let dayName;

switch (day) {
    case 1:
        dayName = "Понедельник";
        break;
    case 2:
        dayName = "Вторник";
        break;
    case 3:
        dayName = "Среда";
        break;
    default:
        dayName = "Неизвестный день";
}

console.log(dayName); // "Среда"
```
*Важно не забывать `break` после каждого `case` — иначе выполнение "провалится" в следующий блок (fall-through).*

## Цикл for
Классический цикл со счётчиком — используется, когда заранее известно количество повторений:
```js
for (let i = 0; i < 5; i++) {
    console.log("Итерация №" + i);
}
// Выведет: Итерация №0, №1, №2, №3, №4
```
Структура `for (инициализация; условие; шаг)`:
- **инициализация** — выполняется один раз перед началом цикла (`let i = 0`);
- **условие** — проверяется перед каждой итерацией, цикл идёт пока `true`;
- **шаг** — выполняется после каждой итерации (`i++`).

## Цикл while
Выполняется, пока условие истинно — используется, когда число повторений заранее неизвестно:
```js
let count = 0;

while (count < 3) {
    console.log("count = " + count);
    count++;
}
```

## Цикл do...while
Отличие от `while`: тело цикла выполнится **как минимум один раз**, даже если условие сразу ложно — проверка идёт **после** выполнения тела:
```js
let num = 10;

do {
    console.log("Выполнится хотя бы раз");
    num++;
} while (num < 5);
```

## Циклы по массивам и объектам

### for...of — перебор значений (массивы, строки)
```js
const fruits = ["яблоко", "банан", "апельсин"];

for (const fruit of fruits) {
    console.log(fruit);
}
```

### for...in — перебор ключей (объекты)
```js
const user = { name: "Иван", age: 25 };

for (const key in user) {
    console.log(key + ": " + user[key]);
}
// Выведет: name: Иван
//          age: 25
```

## Управление циклом: break и continue
```js
// break — полностью прерывает цикл
for (let i = 0; i < 10; i++) {
    if (i === 5) {
        break;
    }
    console.log(i); // выведет 0, 1, 2, 3, 4
}

// continue — пропускает текущую итерацию, переходит к следующей
for (let i = 0; i < 5; i++) {
    if (i === 2) {
        continue;
    }
    console.log(i); // выведет 0, 1, 3, 4 (2 пропущена)
}
```
