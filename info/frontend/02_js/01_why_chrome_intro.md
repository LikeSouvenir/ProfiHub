# Введение в JavaScript. Почему Chrome?

## Что такое JavaScript
**JavaScript (JS)** — это язык программирования, который делает веб-страницы **интерактивными**. Если HTML — это структура, а CSS — оформление, то JavaScript отвечает за **поведение**: реакцию на клики, отправку форм, анимации, загрузку данных без перезагрузки страницы и так далее.

```
HTML  → структура    ("что это за элемент")
CSS   → внешний вид  ("как это выглядит")
JS    → поведение    ("что происходит при взаимодействии")
```

## Почему именно Chrome?
JavaScript выполняется движком — программой, которая читает JS-код и превращает его в машинные команды. У каждого браузера свой движок:

| Браузер | Движок JS |
|---|---|
| Google Chrome / Microsoft Edge | **V8** |
| Mozilla Firefox | SpiderMonkey |
| Safari | JavaScriptCore |

Для обучения и разработки удобнее всего использовать **Chrome**, потому что:
- Движок **V8** — один из самых быстрых и наиболее распространённых (на нём же работает Node.js).
- В Chrome встроены лучшие **инструменты разработчика (DevTools)**: консоль, отладчик, вкладка сети, профилировщик производительности.
- Подавляющее большинство обучающих материалов и документации ориентированы именно на Chrome DevTools.

## Как открыть консоль разработчика
1. Открыть Chrome.
2. Нажать `F12` или `Ctrl+Shift+I` (Windows/Linux) / `Cmd+Option+I` (Mac).
3. Перейти на вкладку **Console**.

В консоли можно писать JS-код построчно и сразу видеть результат — это самый быстрый способ поэкспериментировать с языком.

```js
console.log("Привет, мир!"); // выведет строку в консоль
2 + 2                        // выполнится и покажет результат: 4
```

## Куда писать JavaScript в реальном проекте

### 1. Прямо в HTML-файле, тег `<script>`
```html
<body>
    <h1>Моя страница</h1>

    <script>
        console.log("Скрипт выполнился!");
    </script>
</body>
```

### 2. Внешний файл (рекомендуемый способ)
**script.js**
```js
console.log("Скрипт из внешнего файла");
```
**index.html**
```html
<body>
    <h1>Моя страница</h1>

    <!-- Подключаем внешний файл перед закрывающим </body>,
         чтобы скрипт выполнялся после загрузки всей разметки -->
    <script src="script.js"></script>
</body>
```
Вынесение JS в отдельный файл — стандарт для реальных проектов: код проще читать, переиспользовать и поддерживать отдельно от разметки.

## console.log — главный инструмент отладки
```js
console.log("Простой текст");
console.log(42);
console.log("Значение переменной:", someVariable);
console.error("Это сообщение об ошибке");
console.warn("Это предупреждение");
```
`console.log` — первое, с чем работает практически любой разработчик: выводит значения в консоль, чтобы проверить, что происходит в коде на каждом шаге.
