# Типы данных и операторы

## Объявление переменных
```js
let age = 25;        // переменная, значение можно менять
const name = "Иван";  // константа, значение менять нельзя
var oldWay = "так объявляли раньше"; // устаревший способ, лучше не использовать
```
- `let` — стандартный способ объявить переменную, которую планируется менять.
- `const` — переменную нельзя переприсвоить после объявления (используется по умолчанию, если значение не должно меняться).
- `var` — устаревший вариант из ранних версий JS, имеет неочевидные особенности области видимости (см. следующий конспект) — в современном коде не используется.

## Примитивные типы данных

```js
// Number — числа (целые и дробные, отдельного типа для дробных нет)
let age = 25;
let price = 19.99;

// String — строки (кавычки одинарные, двойные или обратные)
let name = "Алина";
let city = 'Астана';
let greeting = `Привет, ${name}!`; // шаблонная строка — можно вставлять переменные через ${}

// Boolean — логический тип: true или false
let isOnline = true;

// undefined — переменная объявлена, но значение не присвоено
let result;
console.log(result); // undefined

// null — специальное значение "пустоты", осознанное отсутствие значения
let selectedUser = null;

// BigInt — очень большие целые числа
let big = 123456789012345678901234567890n;

// Symbol — уникальный идентификатор (используется редко, в основном во внутренней разработке библиотек)
let id = Symbol("id");
```

## Проверка типа: typeof
```js
console.log(typeof 42);          // "number"
console.log(typeof "hello");     // "string"
console.log(typeof true);        // "boolean"
console.log(typeof undefined);   // "undefined"
console.log(typeof null);        // "object" (историческая особенность/баг языка, но так исторически сложилось)
console.log(typeof {});          // "object"
console.log(typeof function(){});// "function"
```

## Приведение типов (type coercion)
JavaScript — язык с **динамической типизацией**: тип переменной не фиксирован и может неявно преобразовываться:
```js
console.log("5" + 3);   // "53"  — число превращается в строку, идёт склеивание
console.log("5" - 3);   // 2     — строка превращается в число, идёт вычитание
console.log("5" * "2"); // 10    — обе строки превращаются в числа
console.log(1 + true);  // 2     — true превращается в число 1
console.log(1 + null);  // 1     — null превращается в число 0
```
*Из-за таких неочевидных преобразований важно уметь явно приводить типы: `Number("5")`, `String(5)`, `Boolean(0)`.*

## Операторы

### Арифметические
```js
console.log(10 + 3); // 13 — сложение
console.log(10 - 3); // 7  — вычитание
console.log(10 * 3); // 30 — умножение
console.log(10 / 3); // 3.333... — деление
console.log(10 % 3); // 1  — остаток от деления
console.log(10 ** 2);// 100 — возведение в степень
```

### Присваивания
```js
let x = 10;
x += 5;  // x = x + 5  → 15
x -= 3;  // x = x - 3  → 12
x *= 2;  // x = x * 2  → 24
x /= 4;  // x = x / 4  → 6
```

### Сравнения
```js
console.log(5 == "5");   // true  — сравнивает значения, приводя типы (нестрогое сравнение)
console.log(5 === "5");  // false — сравнивает значение И тип (строгое сравнение)
console.log(5 != "5");   // false
console.log(5 !== "5");  // true

console.log(5 > 3);   // true
console.log(5 >= 5);  // true
console.log(5 < 3);   // false
```
*Правило: почти всегда следует использовать строгое сравнение `===` и `!==`, чтобы избежать неожиданного неявного приведения типов.*

### Логические
```js
console.log(true && false); // false — И (оба условия должны быть true)
console.log(true || false); // true  — ИЛИ (достаточно одного true)
console.log(!true);         // false — НЕ (инверсия значения)

// Частый паттерн — задание значения по умолчанию
let userName = null;
let displayName = userName || "Гость"; // если userName "falsy", возьмётся "Гость"
```

### Falsy и truthy значения
При приведении к `boolean` **ложными (falsy)** считаются: `0`, `""` (пустая строка), `null`, `undefined`, `NaN`, `false`. Все остальные значения — **истинные (truthy)**.
```js
if ("") {
    console.log("не выполнится");
}
if ("текст") {
    console.log("выполнится"); // непустая строка — truthy
}
```
