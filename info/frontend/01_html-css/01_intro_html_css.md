# Знакомство с HTML и CSS

## Что такое HTML
**HTML (HyperText Markup Language)** — это язык разметки, который описывает **структуру** и **содержимое** веб-страницы: где заголовок, где текст, где картинка, где кнопка. HTML — это не язык программирования (в нём нет циклов, условий, переменных), а именно язык **разметки**: он размечает контент тегами.

## Что такое CSS
**CSS (Cascading Style Sheets)** — каскадные таблицы стилей. Отвечает за **внешний вид** страницы: цвета, отступы, шрифты, расположение элементов. Если HTML — это скелет и содержимое страницы, то CSS — это её "одежда" и оформление.

## Как они работают вместе
```
HTML  → структура и контент  ("что это за элемент и что в нём написано")
CSS   → внешний вид          ("как этот элемент должен выглядеть")
```

Аналогия: HTML — это стены и комнаты дома (структура), CSS — это ремонт, цвет стен и мебель (оформление).

## Минимальный HTML-документ
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя первая страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый абзац текста.</p>
</body>
</html>
```

### Разбор структуры
| Тег | Назначение |
|---|---|
| `<!DOCTYPE html>` | Указывает браузеру, что документ написан по стандарту HTML5 |
| `<html>` | Корневой элемент, оборачивает всю страницу |
| `<head>` | "Служебная" часть: метаданные, заголовок вкладки, подключение CSS/JS — сам не отображается на странице |
| `<meta charset="UTF-8">` | Указывает кодировку документа (чтобы кириллица и спецсимволы отображались корректно) |
| `<meta name="viewport" ...>` | Настройка отображения на мобильных устройствах |
| `<title>` | Текст, который отображается на вкладке браузера |
| `<body>` | Всё видимое содержимое страницы: тексты, картинки, кнопки и т.д. |

## Как подключить CSS к HTML
Есть три способа — от менее удобного к более удобному.

### 1. Инлайн-стиль (прямо в теге, атрибут style)
```html
<p style="color: red; font-size: 20px;">Красный текст</p>
```
*Используется редко — стили смешиваются с разметкой, сложно поддерживать.*

### 2. Внутренний стиль (тег `<style>` в `<head>`)
```html
<head>
    <style>
        p {
            color: red;
            font-size: 20px;
        }
    </style>
</head>
```

### 3. Внешний файл стилей (рекомендуемый способ)
**style.css**
```css
p {
    color: red;
    font-size: 20px;
}
```
**index.html**
```html
<head>
    <link rel="stylesheet" href="style.css">
</head>
```
Внешний файл позволяет использовать одни и те же стили сразу на нескольких HTML-страницах и хранить оформление отдельно от структуры — это стандарт для реальных проектов.

## Как читать CSS-правило
```css
селектор {
    свойство: значение;
    свойство2: значение2;
}
```
```css
p {
    color: blue;      /* свойство color, значение blue */
    font-size: 18px;  /* свойство font-size, значение 18px */
}
```
Здесь `p` — **селектор** (к каким элементам применяем стиль, в данном случае ко всем `<p>`), а внутри фигурных скобок — список пар "свойство: значение".
