# Базовые селекторы и свойства CSS

## Селекторы: как выбрать нужные элементы

| Селектор | Пример | Что выбирает |
|---|---|---|
| По тегу | `p { }` | Все элементы `<p>` |
| По классу | `.card { }` | Все элементы с `class="card"` |
| По id | `#header { }` | Элемент с `id="header"` |
| Универсальный | `* { }` | Абсолютно все элементы |
| Потомок | `div p { }` | Все `<p>`, находящиеся внутри `<div>` (на любом уровне вложенности) |
| Прямой потомок | `div > p { }` | Только `<p>`, которые являются непосредственным ребёнком `<div>` |
| Несколько селекторов | `h1, h2, h3 { }` | Все `<h1>`, `<h2>` и `<h3>` сразу |
| Состояние (псевдокласс) | `a:hover { }` | Ссылка в момент наведения курсора |

```css
/* Все ссылки */
a {
    color: blue;
}

/* Ссылка при наведении мыши */
a:hover {
    color: red;
    text-decoration: underline;
}

/* Все параграфы внутри блока с классом .content */
.content p {
    line-height: 1.6;
}
```

## Цвет
```css
.box {
    color: red;                 /* именованный цвет */
    color: #ff0000;             /* HEX */
    color: rgb(255, 0, 0);      /* RGB */
    color: rgba(255, 0, 0, 0.5);/* RGB + прозрачность (alpha от 0 до 1) */
}
```
`color` задаёт цвет **текста**, а `background-color` — цвет **фона** элемента.

## Шрифты и текст
```css
.text {
    font-family: Arial, sans-serif; /* если Arial недоступен — браузер возьмёт любой sans-serif */
    font-size: 16px;
    font-weight: bold;               /* или число: 400 (обычный), 700 (жирный) */
    text-align: center;              /* left, right, center, justify */
    line-height: 1.5;                /* межстрочный интервал */
    text-decoration: underline;      /* underline, none, line-through */
}
```

## Размеры и единицы измерения
```css
.box {
    width: 300px;    /* фиксированные пиксели */
    width: 50%;      /* процент от родителя */
    height: 20vh;    /* 20% от высоты видимой области экрана (viewport) */
    font-size: 1.2rem; /* относительно базового размера шрифта корневого элемента */
}
```

## Box Model: отступы, границы и рамки
Каждый HTML-элемент можно представить в виде прямоугольника, состоящего из четырёх слоёв:
```
┌───────────────────────────────┐
│           margin               │  ← внешний отступ (от других элементов)
│  ┌───────────────────────────┐ │
│  │          border            │ │  ← граница/рамка элемента
│  │  ┌───────────────────────┐ │ │
│  │  │       padding          │ │ │  ← внутренний отступ (от рамки до контента)
│  │  │  ┌──────────────────┐  │ │ │
│  │  │  │      content      │  │ │ │  ← сам контент (текст, картинка)
│  │  │  └──────────────────┘  │ │ │
│  │  └───────────────────────┘ │ │
│  └───────────────────────────┘ │
└───────────────────────────────┘
```

```css
.card {
    padding: 20px;             /* отступ внутри рамки, со всех сторон */
    margin: 10px auto;         /* отступ снаружи: 10px сверху/снизу, auto — по центру по горизонтали */
    border: 1px solid #ccc;    /* толщина, стиль, цвет рамки */
    border-radius: 8px;        /* скругление углов */
}
```
Отдельные стороны можно задавать точечно:
```css
.card {
    padding-top: 10px;
    padding-left: 20px;
    margin-bottom: 15px;
}
```

## Фон
```css
.hero {
    background-color: #f5f5f5;
    background-image: url("bg.jpg");
    background-size: cover;      /* картинка заполняет весь блок, сохраняя пропорции */
    background-position: center;
}
```

## Отображение и простое позиционирование
```css
.item {
    display: block;   /* занимает всю ширину строки (как div) */
    display: inline;  /* занимает только свою ширину (как span) */
    display: none;    /* полностью скрывает элемент */
}
```

## Пример: стилизация простой карточки
```html
<div class="card">
    <h2 class="card-title">Заголовок карточки</h2>
    <p class="card-text">Немного описания внутри карточки.</p>
</div>
```
```css
.card {
    width: 300px;
    padding: 16px;
    margin: 20px auto;
    border: 1px solid #ddd;
    border-radius: 10px;
    background-color: #ffffff;
    box-shadow: 0 2px 6px rgba(0, 0, 0, 0.1);
}

.card-title {
    font-size: 20px;
    color: #222;
}

.card-text {
    font-size: 14px;
    color: #666;
    line-height: 1.5;
}
```
