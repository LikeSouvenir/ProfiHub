# Различные IDE: WebStorm и VS Code

Перед тем как начать писать код на React, стоит определиться с редактором. Рассмотрим два самых популярных инструмента.

## Visual Studio Code (VS Code)
**VS Code** — бесплатный, лёгкий редактор кода от Microsoft. Самый популярный выбор для веб-разработки в целом.

**Плюсы:**
- Полностью бесплатный.
- Огромное количество расширений (extensions) под любые задачи.
- Быстрый запуск, не требует мощного компьютера.
- Встроенный терминал и Git-интеграция "из коробки".

**Полезные расширения для React:**
| Расширение | Назначение |
|---|---|
| ES7+ React/Redux/React-Native snippets | Быстрые сниппеты (например, `rafce` создаёт заготовку компонента) |
| ESLint | Подсветка ошибок и нарушений стиля кода в реальном времени |
| Prettier | Автоматическое форматирование кода |
| Auto Rename Tag | При переименовании открывающего JSX/HTML тега автоматически переименовывает закрывающий |
| Simple React Snippets | Дополнительные быстрые заготовки компонентов и хуков |

## WebStorm
**WebStorm** — полноценная IDE (интегрированная среда разработки) от JetBrains, заточенная именно под JavaScript/TypeScript и веб-фреймворки.

**Плюсы:**
- "Из коробки" уже всё настроено: подсветка JSX, автодополнение, рефакторинг, отладчик.
- Более глубокий анализ кода и умные подсказки без установки дополнительных расширений.
- Встроенные инструменты для работы с npm, Git, Docker, базами данных.

**Минусы:**
- Платный (есть бесплатный пробный период и льготные лицензии для студентов).
- Требует больше ресурсов компьютера (RAM, CPU), чем VS Code.

## Какой выбрать
| Критерий | VS Code | WebStorm |
|---|---|---|
| Цена | Бесплатно | Платно (есть триал) |
| Требования к ПК | Низкие | Средние/высокие |
| Настройка под React | Через расширения | Уже готово |
| Гибкость | Очень высокая (любые языки и стек) | Заточена под веб-разработку |

Для обучения и большинства проектов **VS Code** — стандартный, универсальный выбор. **WebStorm** удобен, когда важна максимальная "готовность из коробки" и глубокий встроенный рефакторинг, особенно в больших коммерческих проектах.

## Базовая настройка VS Code для React
1. Установить VS Code с [официального сайта](https://code.visualstudio.com/).
2. Установить расширения: **ES7+ React/Redux/React-Native snippets**, **ESLint**, **Prettier**.
3. Открыть встроенный терминал: `` Ctrl+` `` (Windows/Linux) или `` Cmd+` `` (Mac).
4. Из терминала уже можно создавать и запускать проект (см. следующий конспект).
