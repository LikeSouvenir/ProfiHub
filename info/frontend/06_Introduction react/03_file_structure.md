# Файловая система React-проекта (Vite)

После создания проекта через Vite (`npm create vite@latest`) получаем следующую структуру:

```
my-app/
├── node_modules/        # Все установленные зависимости (не редактируется вручную)
├── public/              # Статические файлы, которые копируются "как есть" (иконки, favicon)
│   └── vite.svg
├── src/                 # Весь исходный код приложения — основная папка для работы
│   ├── assets/          # Картинки, шрифты и другие ресурсы, используемые внутри кода
│   │   └── react.svg
│   ├── App.jsx          # Главный компонент приложения
│   ├── App.css          # Стили для App.jsx
│   ├── main.jsx         # Точка входа — здесь React "монтируется" в HTML-страницу
│   └── index.css        # Глобальные стили всего приложения
├── index.html           # Единственный HTML-файл приложения (React вставляет всё содержимое сюда)
├── package.json         # Список зависимостей и npm-команд проекта
├── package-lock.json    # Точные версии всех установленных зависимостей
└── vite.config.js       # Конфигурация сборщика Vite
```

## Разбор ключевых файлов

### index.html
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8" />
    <title>My App</title>
</head>
<body>
    <!-- React будет "монтировать" всё приложение внутрь этого div -->
    <div id="root"></div>

    <script type="module" src="/src/main.jsx"></script>
</body>
</html>
```
В отличие от обычной вёрстки, здесь почти нет контента внутри `<body>` — единственный элемент `<div id="root">` служит "точкой подключения" всего React-приложения.

### main.jsx — точка входа
```jsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import App from './App.jsx'
import './index.css'

// Находим div#root из index.html и "монтируем" в него компонент App
createRoot(document.getElementById('root')).render(
    <StrictMode>
        <App />
    </StrictMode>,
)
```
- `createRoot(...)` создаёт корень React-дерева внутри найденного HTML-элемента.
- `<App />` — главный компонент, с которого начинается всё дерево интерфейса.
- `<StrictMode>` — служебная обёртка, которая в режиме разработки помогает находить потенциальные проблемы в коде (не влияет на финальную сборку для пользователей).

### App.jsx — главный компонент
```jsx
import './App.css'

function App() {
    return (
        <div className="app">
            <h1>Привет, React!</h1>
        </div>
    )
}

export default App
```
Именно этот файл разработчик редактирует чаще всего в самом начале — здесь описывается разметка и логика главного экрана приложения.

## Папка src — где живёт вся логика
По мере роста проекта внутри `src/` принято заводить дополнительные папки:
```
src/
├── components/   # Переиспользуемые компоненты (кнопки, карточки, формы)
├── pages/        # Компоненты, соответствующие отдельным страницам
├── hooks/        # Собственные React-хуки
├── styles/       # Общие файлы стилей
└── utils/        # Вспомогательные функции, не связанные напрямую с React
```
Такая структура — не жёсткое правило, а сложившаяся практика: она делает большой проект понятнее и позволяет быстро находить нужный файл.
