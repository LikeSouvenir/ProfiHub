# Основные хуки: useState, useEffect

**Хуки (hooks)** — это специальные функции React, которые позволяют компонентам-функциям "подключаться" к возможностям React: хранить состояние, реагировать на изменения, работать с жизненным циклом компонента. Все хуки начинаются с префикса `use`.

## useState — хранение состояния компонента

### Синтаксис
```jsx
import { useState } from 'react';

const [значение, функцияИзменения] = useState(начальноеЗначение);
```
`useState` возвращает **массив из двух элементов**: текущее значение состояния и функцию для его изменения. Обычно этот массив сразу же деструктурируется (см. тему про деструктуризацию массивов/объектов).

### Пример: счётчик
```jsx
import { useState } from 'react';

function Counter() {
    const [count, setCount] = useState(0); // начальное значение — 0

    return (
        <div>
            <p>Текущее значение: {count}</p>
            <button onClick={() => setCount(count + 1)}>Увеличить</button>
        </div>
    );
}
```
Важно: нельзя менять состояние напрямую (`count = count + 1`) — это не заставит React перерисовать компонент. Изменять состояние можно **только** через функцию-сеттер (`setCount`).

### Обновление состояния на основе предыдущего значения
Если новое значение зависит от предыдущего, безопаснее передавать в сеттер функцию, а не готовое значение:
```jsx
setCount(prevCount => prevCount + 1);
```
Это особенно важно, если состояние обновляется несколько раз подряд — так React гарантированно берёт самое актуальное предыдущее значение, а не то, что было "на момент рендера".

### useState с разными типами данных
```jsx
const [name, setName] = useState("");         // строка
const [age, setAge] = useState(0);             // число
const [isVisible, setIsVisible] = useState(true); // булево значение
const [items, setItems] = useState([]);        // массив
const [user, setUser] = useState({ name: "", email: "" }); // объект
```

### Обновление массива и объекта в состоянии
Массивы и объекты в состоянии нельзя изменять "напрямую" (например, через `push` или прямое присваивание свойства) — нужно всегда создавать **новую** копию с изменениями, иначе React может не заметить обновление:
```jsx
const [numbers, setNumbers] = useState([1, 2, 3]);

// ❌ Неправильно — мутация существующего массива
numbers.push(4);
setNumbers(numbers);

// ✅ Правильно — создаём новый массив через spread-оператор
setNumbers([...numbers, 4]);
```
```jsx
const [user, setUser] = useState({ name: "Иван", age: 25 });

// ✅ Создаём новый объект, копируя старые поля и заменяя только age
setUser({ ...user, age: 26 });
```

## useEffect — побочные эффекты и реакция на изменения

### Зачем нужен useEffect
Некоторые действия не связаны напрямую с самим рендерингом JSX: запрос к серверу, подписка на события, работа с таймерами, логирование в консоль. Такие действия называются **побочными эффектами (side effects)**, и для них существует хук `useEffect`.

### Синтаксис
```jsx
import { useEffect } from 'react';

useEffect(() => {
    // код побочного эффекта
}, [список_зависимостей]);
```

### Вариант 1: эффект выполняется при каждом рендере
```jsx
useEffect(() => {
    console.log("Компонент отрендерился");
}); // массив зависимостей не указан
```

### Вариант 2: эффект выполняется только один раз, при первом рендере
```jsx
useEffect(() => {
    console.log("Компонент появился на экране (монтирование)");
}, []); // пустой массив зависимостей
```

### Вариант 3: эффект выполняется при изменении конкретных значений
```jsx
const [count, setCount] = useState(0);

useEffect(() => {
    console.log("count изменился, новое значение:", count);
}, [count]); // сработает заново каждый раз, когда меняется count
```

### Функция очистки (cleanup)
Если внутри `useEffect` подписываемся на что-то (таймер, событие), важно "отписаться", когда компонент исчезает со страницы — для этого `useEffect` может вернуть функцию очистки:
```jsx
useEffect(() => {
    const timerId = setInterval(() => {
        console.log("Тик");
    }, 1000);

    // Функция очистки — выполнится при удалении компонента со страницы
    return () => {
        clearInterval(timerId);
    };
}, []);
```

## Сводная таблица: как часто выполняется useEffect
| Массив зависимостей | Когда выполняется |
|---|---|
| Не указан | После каждого рендера компонента |
| `[]` (пустой) | Только один раз, после первого рендера |
| `[значение]` | После первого рендера, и затем каждый раз, когда `значение` меняется |

## Пример: useState + useEffect вместе
```jsx
import { useState, useEffect } from 'react';

function Timer() {
    const [seconds, setSeconds] = useState(0);

    useEffect(() => {
        const timerId = setInterval(() => {
            // Используем функцию-обновление, так как новое значение зависит от предыдущего
            setSeconds(prev => prev + 1);
        }, 1000);

        return () => clearInterval(timerId); // очистка при удалении компонента
    }, []); // подписываемся на таймер только один раз

    return <p>Прошло секунд: {seconds}</p>;
}
```
