# Скачивание библиотек

## Зачем нужна отдельная библиотека для маршрутизации
Vite и React "из коробки" создают только **одну** HTML-страницу (`index.html`) — это называется **SPA (Single Page Application)**. Чтобы внутри такого приложения можно было переключаться между разными "страницами" (Главная, О нас, Каталог и т.д.) без полной перезагрузки браузера, используется отдельная библиотека маршрутизации.

Самая популярная библиотека для этого в экосистеме React — **React Router**, а именно её пакет для веба — **react-router-dom**.

## Установка react-router-dom
В уже существующем React-проекте (созданном ранее через Vite):
```bash
cd my-app
npm install react-router-dom
```

После установки библиотека появится в `package.json`:
```json
"dependencies": {
    "react": "^18.3.1",
    "react-dom": "^18.3.1",
    "react-router-dom": "^6.26.0"
}
```

## Проверка установки
```bash
npm list react-router-dom
```
Если команда выводит установленную версию — библиотека готова к использованию, и её можно импортировать в компонентах:
```jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';
```

## Другие типовые библиотеки, которые часто ставят вместе с роутингом
Хотя для самого роутинга достаточно `react-router-dom`, в реальных проектах его часто устанавливают вместе с:
```bash
npm install axios        # для запросов к API (например, получение списка товаров с сервера)
```
Для задач с контекстом (`createContext`/`useContext`), которые понадобятся дальше в этой теме, дополнительные библиотеки не нужны — это встроенный функционал самого React.
