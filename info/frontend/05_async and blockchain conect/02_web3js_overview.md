# Web3.js: мини-обзор библиотеки

## Что такое Web3.js
**Web3.js** — это JavaScript-библиотека, которая позволяет коду на JS "общаться" с блокчейном Ethereum (и совместимыми сетями): читать данные из блокчейна, отправлять транзакции, взаимодействовать со смарт-контрактами. Именно через такие библиотеки фронтенд-приложения (например, сайт с кнопкой "Подключить кошелёк") взаимодействуют с сетью.

Так как вся работа с блокчейном по своей природе **асинхронна** (нужно дождаться ответа от ноды или подтверждения транзакции в сети), практически все методы Web3.js возвращают `Promise` — отсюда прямая связь с темой `async/await` из предыдущего конспекта.

## Установка
```bash
npm install web3
```
```js
const { Web3 } = require("web3");
// или в среде с поддержкой ES-модулей:
// import { Web3 } from "web3";
```

## Провайдер (Provider) — точка подключения к сети
Провайдер — это то, через что Web3.js подключается к конкретной ноде блокчейна (например, к запущенному локально Geth):
```js
const web3 = new Web3("http://127.0.0.1:8545"); // HTTP-подключение к локальной ноде Geth
```
Также поддерживаются WebSocket-провайдеры (нужны, чтобы подписываться на события в реальном времени):
```js
const web3 = new Web3("ws://127.0.0.1:8546");
```

## Модуль web3.eth — основной модуль для работы с блокчейном
```js
// Получить список аккаунтов, доступных на ноде
const accounts = await web3.eth.getAccounts();
console.log(accounts); // ["0xAbC123...", "0xDeF456..."]

// Получить баланс аккаунта (в wei)
const balanceWei = await web3.eth.getBalance(accounts[0]);
console.log(balanceWei); // "1000000000000000000000"

// Получить номер последнего блока
const blockNumber = await web3.eth.getBlockNumber();
console.log(blockNumber);
```

## Модуль web3.utils — вспомогательные функции
```js
// Перевод между единицами измерения эфира
console.log(web3.utils.toWei("1", "ether"));   // "1000000000000000000" (wei)
console.log(web3.utils.fromWei("1000000000000000000", "ether")); // "1"

// Проверка, является ли строка валидным адресом
console.log(web3.utils.isAddress("0xAbC123...")); // true / false
```
*Важно: суммы эфира в блокчейне хранятся в **wei** — минимальной единице (1 ETH = 10^18 wei). `toWei`/`fromWei` избавляют от необходимости вручную считать нули.*

## Отправка простой транзакции (перевод эфира)
```js
async function sendEther() {
    const accounts = await web3.eth.getAccounts();

    const receipt = await web3.eth.sendTransaction({
        from: accounts[0],
        to: accounts[1],
        value: web3.utils.toWei("1", "ether"),
    });

    console.log("Транзакция подтверждена:", receipt.transactionHash);
}
```
`sendTransaction` возвращает Promise, который выполнится (resolve) только после того, как транзакция будет включена в блок — благодаря `await` код дожидается этого момента, прежде чем продолжить выполнение.

## Работа со смарт-контрактами (кратко)
Чтобы вызывать функции конкретного смарт-контракта, Web3.js нужно знать два параметра: **адрес** контракта в сети и его **ABI** (описание интерфейса контракта — разберём подробно в следующем конспекте).
```js
const contract = new web3.eth.Contract(abi, contractAddress);

// Чтение данных (не требует транзакции, не тратит газ)
const value = await contract.methods.someGetter().call();

// Запись данных (требует транзакции, тратит газ, меняет состояние блокчейна)
await contract.methods.someSetter(newValue).send({ from: accounts[0] });
```
