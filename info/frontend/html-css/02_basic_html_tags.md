# Базовые теги HTML

Тег в HTML почти всегда состоит из открывающей и закрывающей части: `<тег>содержимое</тег>`. Есть и теги без содержимого — так называемые **самозакрывающиеся** (например, `<img>`, `<br>`).

## Заголовки
От `<h1>` (самый крупный, главный заголовок страницы) до `<h6>` (самый мелкий). На странице обычно только один `<h1>`.
```html
<h1>Заголовок страницы</h1>
<h2>Заголовок раздела</h2>
<h3>Подраздел</h3>
```

## Текст и абзацы
```html
<p>Обычный абзац текста.</p>

<b>Жирный текст</b>
<strong>Жирный текст со смысловым акцентом (важность)</strong>

<i>Курсив</i>
<em>Курсив со смысловым акцентом (выделение)</em>

<br>  <!-- Перенос строки -->
<hr>  <!-- Горизонтальная разделительная линия -->
```
*Разница `b` vs `strong` и `i` vs `em`: визуально они выглядят одинаково, но `strong`/`em` несут смысловую нагрузку — это важно для скринридеров и поисковых систем (семантика).*

## Ссылки
```html
<a href="https://example.com">Перейти на example.com</a>

<!-- Открыть в новой вкладке -->
<a href="https://example.com" target="_blank">Открыть в новой вкладке</a>

<!-- Ссылка на другую страницу того же сайта -->
<a href="/about.html">О нас</a>

<!-- Ссылка на почту -->
<a href="mailto:test@mail.com">Написать нам</a>
```

## Изображения
```html
<img src="cat.jpg" alt="Фотография кота" width="300" height="200">
```
- `src` — путь к изображению (обязательный атрибут).
- `alt` — текстовое описание, если картинка не загрузилась, а также для скринридеров (обязательно с точки зрения доступности).
- `width` / `height` — размеры (можно и не задавать, тогда будет использован реальный размер картинки).

## Списки
### Маркированный список
```html
<ul>
    <li>Яблоко</li>
    <li>Банан</li>
    <li>Апельсин</li>
</ul>
```
### Нумерованный список
```html
<ol>
    <li>Открыть редактор кода</li>
    <li>Создать файл index.html</li>
    <li>Написать разметку</li>
</ol>
```

## Контейнеры: div и span
```html
<!-- div — блочный контейнер, занимает всю ширину, начинается с новой строки -->
<div>
    <p>Это блок с текстом</p>
</div>

<!-- span — строчный контейнер, не переносит на новую строку -->
<p>Обычный текст, но <span style="color: red;">это слово красное</span>, а остальное — нет.</p>
```
`div` и `span` сами по себе не несут смысла — это "универсальные обёртки", которые часто используют вместе с классами (`class`) для стилизации через CSS или для группировки элементов.

## Атрибуты class и id
```html
<div class="card">Карточка товара</div>
<div id="header">Шапка сайта</div>
```
- `class` — можно присвоить **нескольким** элементам, используется для многократного применения одних стилей.
- `id` — должен быть **уникальным** на странице, обычно применяется к одному конкретному элементу.

```css
.card {
    border: 1px solid gray;
}

#header {
    background-color: black;
}
```
*В CSS класс обозначается точкой (`.card`), а id — решёткой (`#header`).*

## Таблицы
```html
<table>
    <tr>
        <th>Имя</th>
        <th>Возраст</th>
    </tr>
    <tr>
        <td>Алина</td>
        <td>20</td>
    </tr>
</table>
```
- `<table>` — таблица целиком.
- `<tr>` (table row) — строка.
- `<th>` (table header) — ячейка заголовка (жирным по умолчанию).
- `<td>` (table data) — обычная ячейка с данными.

## Формы
```html
<form action="/submit" method="POST">
    <label for="name">Имя:</label>
    <input type="text" id="name" name="name" placeholder="Введите имя">

    <label for="email">Email:</label>
    <input type="email" id="email" name="email">

    <button type="submit">Отправить</button>
</form>
```
- `<input type="text">` — однострочное текстовое поле.
- `<input type="email">` — поле с базовой валидацией email-формата.
- `<label for="...">` — подпись, связанная с полем по `id` (клик по подписи ставит фокус в поле).
- `<button type="submit">` — кнопка отправки формы.

## Семантические теги (HTML5)
Вместо того чтобы всё оборачивать в безликие `<div>`, HTML5 предлагает теги, которые сразу говорят браузеру и разработчику **смысл** блока:
```html
<header>Шапка сайта: логотип, меню</header>
<nav>Навигационное меню</nav>
<main>
    <section>Раздел страницы</section>
    <article>Отдельная статья или пост</article>
</main>
<aside>Боковая колонка, доп. информация</aside>
<footer>Подвал сайта: копирайт, ссылки</footer>
```
Семантические теги улучшают доступность (screen readers) и SEO — поисковики лучше понимают структуру страницы.
