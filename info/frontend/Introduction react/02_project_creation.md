# Создание проекта

## Требования
Перед началом нужно установить **Node.js** (включает в себя `npm` — менеджер пакетов). Проверить, что всё установлено:
```bash
node -v
npm -v
```

## Способ 1: Vite (рекомендуемый способ)
**Vite** — современный инструмент сборки, который создаёт и запускает React-проекты значительно быстрее, чем более старые инструменты.

```bash
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev
```
- `my-app` — название папки проекта (можно указать любое своё).
- `--template react` — указывает, что нужен шаблон именно для React (Vite поддерживает и другие фреймворки: Vue, Svelte и т.д.).
- `npm install` — устанавливает все зависимости проекта, перечисленные в `package.json`.
- `npm run dev` — запускает локальный dev-сервер (обычно на `http://localhost:5173`) с автоматическим обновлением страницы при изменении кода (Hot Module Replacement).

## Способ 2: Create React App (устаревающий, но всё ещё встречается)
```bash
npx create-react-app my-app
cd my-app
npm start
```
Раньше был стандартом для старта React-проектов, но заметно медленнее Vite при разработке и сборке, поэтому в новых проектах чаще выбирают Vite.

## Основные npm-команды после создания проекта
```bash
npm run dev      # запуск проекта в режиме разработки (Vite)
npm run build     # сборка финальной, оптимизированной версии для продакшена
npm run preview   # локальный просмотр уже собранной сборки
```

## Установка дополнительных библиотек
Любая сторонняя библиотека устанавливается через `npm install`:
```bash
npm install react-router-dom   # например, для маршрутизации между страницами
npm install axios              # например, для запросов к API
```
После установки библиотека появляется в `package.json` (в разделе `dependencies`) и физически сохраняется в папку `node_modules`.

## Первый запуск: что происходит
После `npm run dev` Vite запускает локальный сервер, компилирует JSX и современный JavaScript "на лету", и открывает страницу, на которой отображается стандартный стартовый экран React-проекта — его и предстоит переделать под свою задачу, отредактировав файл `src/App.jsx`.
