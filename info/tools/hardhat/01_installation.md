# Установка и настройка Hardhat

## Что такое Hardhat
**Hardhat** — среда разработки (development environment) для смарт-контрактов на Ethereum. Объединяет в себе: компиляцию Solidity, локальную тестовую блокчейн-сеть, фреймворк для тестирования, инструменты для деплоя и отладки — всё в одном инструменте с единым конфигурационным файлом.

По сравнению с ручной сборкой через Remix + Geth (как в более ранних темах), Hardhat даёт полностью автоматизированный, повторяемый рабочий процесс: написал контракт → написал тесты → один командой всё скомпилировал, протестировал и задеплоил.

## Требования
Нужен установленный **Node.js** (включает `npm`):
```bash
node -v
npm -v
```

## Создание нового проекта
```bash
mkdir my-hardhat-project
cd my-hardhat-project
npm init -y

npm install --save-dev hardhat
```

Инициализация самого Hardhat-проекта:
```bash
npx hardhat init
```
Появится интерактивное меню выбора:
- **Create a JavaScript project** — стандартный проект с тестами на JS.
- **Create a TypeScript project** — тот же проект, но с поддержкой TypeScript.
- **Create an empty hardhat.config.js** — минимальная конфигурация без примеров.

Для обучения и большинства задач достаточно варианта **JavaScript project** — Hardhat сразу создаст пример контракта, пример теста и пример скрипта деплоя.

## Структура созданного проекта
```
my-hardhat-project/
├── contracts/            # Файлы .sol — исходный код смарт-контрактов
│   └── Lock.sol
├── test/                 # Тесты (JS/TS)
│   └── Lock.js
├── scripts/              # Скрипты деплоя и вспомогательные скрипты
│   └── deploy.js
├── ignition/             # Модули Hardhat Ignition — современный способ описания деплоя
│   └── modules/
├── hardhat.config.js     # Главный конфигурационный файл
├── package.json
└── node_modules/
```

## hardhat.config.js — главный конфиг
```js
require("@nomicfoundation/hardhat-toolbox");

module.exports = {
    solidity: "0.8.24",

    networks: {
        // Локальная встроенная сеть Hardhat — поднимается автоматически при тестах
        hardhat: {},

        // Пример подключения к внешней тестовой сети через RPC-провайдера
        sepolia: {
            url: process.env.SEPOLIA_RPC_URL || "",
            accounts: process.env.PRIVATE_KEY ? [process.env.PRIVATE_KEY] : [],
        },
    },
};
```
- `solidity` — версия компилятора Solidity, которую нужно использовать для проекта.
- `networks` — список сетей, к которым может подключаться Hardhat: встроенная локальная сеть (`hardhat`), а также любые внешние сети (тестовые или основная сеть Ethereum) через RPC-адрес и приватный ключ.

## hardhat-toolbox — набор плагинов "из коробки"
```bash
npm install --save-dev @nomicfoundation/hardhat-toolbox
```
`hardhat-toolbox` — это единый пакет, объединяющий сразу несколько часто используемых плагинов: Ethers.js для взаимодействия с контрактами, Chai-матчеры для тестов, отчёт по расходу газа, покрытие тестами (coverage) и другие — избавляет от необходимости устанавливать и настраивать каждый плагин по отдельности.

## Основные команды Hardhat
```bash
npx hardhat compile      # скомпилировать все контракты из папки contracts/
npx hardhat test         # запустить все тесты из папки test/
npx hardhat node         # поднять локальную блокчейн-ноду Hardhat с готовыми тестовыми аккаунтами
npx hardhat clean        # очистить кэш и артефакты предыдущей компиляции
npx hardhat help         # список всех доступных команд
```

## npx hardhat node — локальная тестовая сеть
```bash
npx hardhat node
```
Запускает локальную блокчейн-ноду (аналог `geth --dev` из темы про Geth), но специально заточенную под разработку: 20 тестовых аккаунтов с балансом 10 000 ETH каждый, мгновенное подтверждение транзакций, подробные логи всех вызовов контрактов прямо в консоль.

```
Accounts
========
Account #0: 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266 (10000 ETH)
Private Key: 0xac0974bec39a17e36ba4a6b4d238ff944bca...
...
```
Эти тестовые аккаунты можно использовать при деплое и ручном тестировании — они существуют только в рамках локальной сети и не имеют отношения к реальным средствам.
