# Продвинутые параметры запуска Geth и управление аккаунтами

При разработке и тестировании сложных систем в Geth часто бывает необходимо тонко настроить работу сети: изменить скорость выпуска блоков, управлять балансами или настроить майнинг. Ниже представлены наиболее полезные параметры.

## Управление временем добычи блоков (dev.period)

По умолчанию в режиме `--dev` Geth использует "майнинг по требованию" (On-Demand Mining). Это означает, что новый блок создается только тогда, когда в сеть отправляется транзакция. 

Однако для тестирования некоторых контрактов (например, завязанных на время `block.timestamp` или номер блока `block.number`) требуется, чтобы блоки добывались постоянно, как в настоящей сети.

**Параметр `--dev.period`** позволяет установить фиксированный интервал генерации блоков (в секундах).

**Пример:**
```bash
geth --datadir "" --dev --dev.period 2
```
В этом случае Geth будет создавать новый блок ровно каждые 2 секунды, даже если в сети нет никаких транзакций. Установка `--dev.period 0` вернет режим по умолчанию (майнинг только при наличии транзакций).

## Расширенное управление Genesis и балансами

### Добавление новых пользователей (Alloc)
Как мы выяснили в базовом руководстве, балансы инициализируются в блоке `alloc` файла `genesis.json`.
Если в процессе работы вам потребовалось добавить новые адреса с балансами, лучше всего сделать это до инициализации (команды `init`).

Формат баланса — это строка с числом в минимальных единицах (wei):
- 1 ETH = 1 000 000 000 000 000 000 wei.
- 100 ETH = "100000000000000000000"

Пример заполнения `alloc` для двух аккаунтов:
```json
"alloc": {
  "0000000000000000000000000000000000000001": {
    "balance": "1000000000000000000000"
  },
  "A1b2c3d4e5f6A1b2c3d4e5f6A1b2c3d4e5f6A1b2": {
    "balance": "500000000000000000000"
  }
}
```
*Важно: Адреса указываются без префикса `0x`.*

### Как перевести баланс без Remix
Если сеть уже работает, и вам срочно нужно перевести эфир с одного аккаунта (созданного через `account new`) на другой, воспользуйтесь JavaScript-консолью Geth.
В работающей консоли выполните:
```javascript
eth.sendTransaction({
    from: eth.accounts[0], 
    to: "0xВашДругойАдрес", 
    value: web3.toWei(10, "ether")
})
```
*Убедитесь, что аккаунт-отправитель был предварительно разблокирован параметром `--unlock`.*

## Сетевые параметры (Network & API)

Для сложного тестирования (например, при подключении фронтенда или сторонних скриптов) вам могут пригодиться следующие HTTP параметры:
- `--http.vhosts "*"` — решает проблему "invalid host", если вы стучитесь к ноде по домену, а не по `localhost`.
- `--ws` — включает WebSocket сервер (нужно для подписки на события смарт-контрактов через Web3.js / Ethers.js).
- `--ws.port 8546` — порт для WebSockets.
- `--ws.api="eth,net,web3"` — доступные пространства имён для WebSockets.
- `--mine --miner.threads=1` — в старых версиях или при запуске без `--dev` принудительно включает майнинг в 1 поток.
