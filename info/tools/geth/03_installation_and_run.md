# Установка и запуск своей сети на Geth

В этом руководстве мы разберем пошаговый процесс создания собственной приватной сети Ethereum с использованием Geth, включая создание аккаунтов, настройку Genesis-блока и подключение Remix.

### Шаг 1: Установка
1. Скачайте установщик 64-bit Go-Ethereum (например, версии 1.14.11) с [официального сайта](https://geth.ethereum.org/downloads).
2. Запустите установщик и согласитесь с лицензией.
3. Обязательно поставьте галочки для установки **Geth** и **инструментов разработки** (Development tools).
4. Укажите удобный путь установки.

### Шаг 2: Создание проекта
Создайте пустую папку на компьютере, которая будет служить директорией для вашего проекта (базы данных узла).

### Шаг 3: Первый запуск для инициализации
Откройте терминал (или командную строку `cmd` в Windows) в папке вашего проекта и запустите Geth в режиме разработчика:
```bash
geth --datadir "" --dev
```
- Параметр `--datadir ""` отвечает за расположение данных. Пустые кавычки означают использование текущей директории.
- Параметр `--dev` включает режим разработчика (быстрый майнинг, тестовые настройки).

### Шаг 4: Остановка Geth
После успешного запуска и появления логов в терминале сразу остановите Geth (нажмите комбинацию клавиш `Ctrl + C`). Это действие создаст необходимые базовые файлы в папке.

### Шаг 5: Получение конфигурации Genesis
Теперь нам нужно получить совместимую конфигурацию Genesis для нашей сети. Выполните команду:
```bash
geth --datadir "" --dev dumpgenesis
```
В терминал будет выведен JSON-объект. Это и есть базовые настройки вашей сети.

### Шаг 6: Сохранение genesis.json
Создайте файл `genesis.json` в вашей папке проекта.
Скопируйте весь JSON-вывод из шага 5 и вставьте его в этот файл. Позже нам нужно будет изменить в нем только блок `alloc`.

### Шаг 7: Очистка базы данных
Удалите появившуюся папку `geth` (или `chaindata` внутри `geth`) из вашей директории проекта, чтобы инициализировать чистую базу с нашим новым Genesis-блоком на следующих шагах.

### Шаг 8: Создание нового аккаунта
Создадим аккаунт, который будет иметь баланс со старта сети.
```bash
geth --datadir "" account new
```
Вас попросят указать и подтвердить пароль для нового аккаунта (можно оставить пустым, нажав Enter).
В выводе команды вы увидите ваш **публичный адрес** (Public address of the key). Скопируйте его, он нам понадобится.

### Шаг 9: Редактирование баланса в genesis.json
Откройте файл `genesis.json`. Найдите объект `"alloc": {}` и добавьте туда ваш новый адрес:
```json
"alloc": {
  "ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ_БЕЗ_0x": {
    "balance": "1000000000000000000000"
  }
}
```
*Примечание: Баланс указывается в wei (1 ETH = 10^18 wei). Адрес и баланс обязательно должны быть в кавычках (как строки). Если нужно несколько аккаунтов, повторите шаги 8 и 9.*

### Шаг 10: Инициализация сети
Примените настройки из вашего файла:
```bash
geth --datadir "" init genesis.json
```
*(Если появится предупреждение "Head block is not reachable" — не переживайте, это нормально при старте чистой сети).*

### Шаг 11: Запуск рабочей сети
Теперь запускаем сеть с настройками HTTP API для подключения сторонних приложений (Remix, Metamask):
```bash
geth --datadir "" --dev --http --http.api="eth,web3,net" --http.corsdomain "*" --http.port 8545 --networkid 1337 --allow-insecure-unlock --unlock "ВАШ_АДРЕС_С_ШАГА_8" console
```

**Разбор параметров:**
- `--http`: Включает обмен информацией по протоколу HTTP.
- `--http.api="eth,web3,net"`: Разрешает использовать функции из указанных пространств имён.
- `--http.corsdomain "*"`: Разрешает запросы с любых доменов (нужно для работы Remix).
- `--http.port 8545`: Порт для HTTP сервера.
- `--networkid 1337`: Идентификатор сети (должен совпадать с `chainId` из genesis.json).
- `--allow-insecure-unlock`: Разрешает разблокировку аккаунтов по HTTP.
- `--unlock "АДРЕС"`: Аккаунты, которые будут разблокированы для отправки транзакций. Можно указать несколько через запятую.
- `console`: Запускает интерактивную консоль JavaScript прямо в этом терминале.

*После ввода команды потребуется ввести пароли от аккаунтов из параметра unlock. (Если вы оставили их пустыми, просто нажмите Enter).*

### Шаг 12 (Опционально): Подключение через второй терминал
Вместо параметра `console` в шаге 11, вы можете открыть новый терминал и подключиться к уже работающей сети:
```bash
geth attach http://127.0.0.1:8545
```

### Шаг 13: Развертывание контрактов из Remix
Чтобы публиковать смарт-контракты прямо из Remix IDE:
1. Зайдите во вкладку **Deploy & run transactions**.
2. В выпадающем списке **ENVIRONMENT** выберите **Custom - External Http Provider**.
3. Появится окно с URL. Так как мы указали порт `8545`, оставьте значение по умолчанию (`http://127.0.0.1:8545`) и нажмите «OK».

**Готово!** Теперь ваш Remix подключен к локальной сети Geth, и вы можете разворачивать контракты с вашего аккаунта без траты реальных эфиров.
