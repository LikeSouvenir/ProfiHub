# Готовые Data API: обзор раздела

## Проблема, которую решают эти сервисы

Предыдущий раздел (`01_envio`) разбирал, как поднять **собственный** индексатор: контракт → события → своя схема → своя GraphQL-выдача. Это правильный путь, когда данные специфичны для вашего проекта — как `TaskLog` из практики.

Но для типовых задач — баланс кошелька, список NFT, история транзакций, цена токена — поднимать индексатор избыточно. Эти данные нужны тысячам приложений одновременно, и крупные провайдеры уже проиндексировали их за вас. Остаётся сделать один HTTP-запрос.

**Правило выбора:**

| Ситуация | Что использовать |
|---|---|
| Нужны стандартные данные (баланс, NFT, история) | Готовый Data API |
| Нужна собственная агрегация по контракту проекта | Свой индексатор (Envio, The Graph) |
| Нужны и те, и другие | Комбинация: Data API для стандартных данных + свой индексатор для специфичных сущностей |

На хакатоне и чемпионате это почти всегда экономия часов: не нужно разворачивать Docker, писать схему и обработчики — только получить API-ключ и сделать запрос.

## Кто есть на рынке

| Сервис | Формат API | Сильная сторона |
|---|---|---|
| **Alchemy** | JSON-RPC (`alchemy_*`) + REST Data API | Глубже всех интегрирован с нодами; Enhanced API поверх своей инфраструктуры |
| **Moralis** | REST | Самый широкий охват «из коробки» — Wallet API отдаёт всё одним вызовом |
| **GoldRush (Covalent)** | REST (`api.covalenthq.com`) | Явные кредиты и предсказуемая цена; 100+ сетей unified-запросом |
| **QuickNode** | JSON-RPC (`qn_*`) через marketplace-аддоны | Продолжение вашей же RPC-ноды: тот же эндпоинт, тот же ключ |
| **Bitquery** | GraphQL (запросы + WebSocket-подписки) | Аналитика DEX-торгов и произвольные агрегации без готовых REST-маршрутов |

## Важные новости 2026 года — учитывайте при подготовке

1. **Alchemy SDK JS устарел.** `alchemy-sdk-js` архивируется в январе 2026. Новые проекты используют напрямую `fetch` к Data API или JSON-RPC методы `alchemy_*`, либо Viem/Ethers для стандартных вызовов ноды.
2. **Sim API (Dune) закрывается 1 августа 2026.** Если в старых материалах или примерах встречается `api.sim.dune.com` — это мёртвый сервис. Alchemy и Moralis оба выпустили гайды миграции с Sim, что показывает: рынок консолидируется вокруг нескольких крупных игроков.
3. **Covalent → GoldRush.** Covalent ребрендировался в GoldRush ещё в 2024 году, но многие материалы в сети всё ещё называют его Covalent. Домен документации — `goldrush.dev`, но базовый URL API остался `api.covalenthq.com`.

## Что объединяет все Data API

Независимо от вендора, у типового запроса «баланс/NFT/история» одна и та же форма:

```
Вход:  адрес кошелька + сеть (+ фильтры: контракт, диапазон блоков, типы токенов)
Выход: пагинированный список (балансы / NFT / транзакции) с метаданными
```

Различия — в деталях: JSON-RPC против REST против GraphQL, где лежит API-ключ, как считаются лимиты (запросы в секунду, «кредиты» за вызов, compute units).
