# 12. Полная таблица критериев оценки

Официальная рубрика модуля Г, по которой судьи выставляют баллы 0–3 по каждому пункту. Используйте её как финальный чек-лист перед докладом — по каждой строке честно оцените, на какой балл тянет ваш текущий слайд, и доработайте то, что ниже 3.

## 1. Представлено подробное техническое задание
| Балл | Критерий |
|---|---|
| 0 | не представлено |
| 1 | представлено на самом общем уровне |
| 2 | представлено, часть задач детально проработана |
| 3 | представлено, все задачи тщательно проработаны |
→ подробности в файле 01

→ подробности в файле 11

## 14. В презентации нет орфографических ошибок
Формальный, но легко теряемый пункт — обязательно вычитайте текст на слайдах перед докладом, желательно кем-то, кто не писал сам текст (свежий взгляд ловит опечатки лучше).
