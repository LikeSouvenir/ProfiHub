# ABI, Единицы измерения времени и Эфира

## Что такое ABI?
**ABI (Application Binary Interface)** — это стандартный способ взаимодействия со смарт-контрактами в экосистеме Ethereum, как извне блокчейна (например, из JavaScript frontend'а), так и между самими контрактами.

Когда вы пишете код на Solidity и компилируете его, получается две вещи:
1. **Байткод** — нули и единицы, которые деплоятся в EVM.
2. **ABI** — JSON-файл, который описывает, какие функции есть в контракте, какие аргументы они принимают и что возвращают.

Внутри самого Solidity встроенный объект `abi` позволяет кодировать и декодировать данные в понятный для EVM байтовый формат. 
Самые популярные методы:
- `abi.encode(...)` — полное кодирование данных (с сохранением информации о типах).
- `abi.encodePacked(...)` — плотное кодирование данных (без метаданных), экономит место. Часто используется для генерации хэшей (например, `keccak256(abi.encodePacked(a, b))`).
- `abi.encodeWithSignature("func(uint256)", arg)` — кодирует вызов конкретной функции (используется вместе с `call`).

## Единицы измерения Эфира (ether, wei, eth)
В смарт-контрактах нет дробных чисел (float). Все вычисления производятся в целых числах. Чтобы работать с дробными суммами (например, 0.5 ETH), используется система **decimals** (знаки после запятой) и минимальные единицы.

Базовая единица в Ethereum называется **wei**. 
`1 Ether` = `1 000 000 000 000 000 000 wei` (10^18 wei, то есть 18 decimals).

Solidity предоставляет удобные суффиксы для работы с эфиром, чтобы вам не приходилось писать нули вручную:
- `wei` — базовая единица (1).
- `gwei` — $10^9$ wei (обычно в gwei измеряется цена газа).
- `ether` — $10^{18}$ wei.

```solidity
uint public oneWei = 1 wei;
uint public oneGwei = 1 gwei;
uint public oneEther = 1 ether;

// Эти условия истинны
bool public test1 = (1 wei == 1);
bool public test2 = (1 ether == 1000000000000000000);
```

### Что такое decimals?
В токенах стандарта ERC-20 (USDT, USDC, DAI) используется тот же подход. Переменная `decimals` показывает, на сколько порядков нужно разделить баланс, чтобы получить привычное глазу число. Для эфира это 18. Для USDT это 6 (то есть 1 USDT = 1000000 минимальных единиц токена).

## Единицы измерения времени
Solidity также имеет встроенные суффиксы для работы со временем. Базовой единицей времени является **секунда** (поскольку `block.timestamp` возвращает секунды).

- `seconds` — базовая единица.
- `minutes` — 60 секунд.
- `hours` — 3600 секунд.
- `days` — 86400 секунд.
- `weeks` — 604800 секунд.

*Примечание: Суффикс `years` был удален в Solidity 0.5.0 из-за сложности учета високосных годов.*

```solidity
uint public oneMinute = 1 minutes; // 60
uint public oneDay = 1 days;       // 86400

function isReady(uint _startTime) public view returns (bool) {
    // Проверка, прошла ли одна неделя с момента _startTime
    return block.timestamp >= _startTime + 1 weeks;
}
```
