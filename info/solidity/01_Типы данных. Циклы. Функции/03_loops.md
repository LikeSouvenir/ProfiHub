# Циклы в Solidity

Solidity поддерживает классические конструкции циклов, унаследованные из языков C/C++/JavaScript.

**Важное правило:** В смарт-контрактах следует быть крайне осторожным с циклами, особенно если количество итераций может неограниченно расти. Каждая итерация стоит Газ. Если цикл окажется слишком долгим, выполнение транзакции превысит "Gas Limit" и упадет с ошибкой (Out of Gas), а эфир за транзакцию сгорит впустую.

## 1. Цикл for
Самый часто используемый цикл, особенно для перебора массивов фиксированной или известной длины.

```solidity
function forLoopExample() public pure returns (uint) {
    uint sum = 0;
    // инициализация; условие; шаг
    for (uint i = 0; i < 10; i++) {
        // Остановка текущей итерации и переход к следующей
        if (i == 5) continue;
        
        sum += i;
        
        // Полный выход из цикла
        if (i == 8) break;
    }
    return sum;
}
```

## 2. Цикл while
Цикл `while` проверяет условие **до** начала итерации. Если условие ложно изначально, код внутри цикла ни разу не выполнится.

```solidity
function whileLoopExample() public pure returns (uint) {
    uint count = 0;
    
    while (count < 5) {
        count++; // Убедитесь, что условие выхода рано или поздно наступит, иначе - бесконечный цикл!
    }
    
    return count; // Вернет 5
}
```

## 3. Цикл do-while
В отличие от `while`, цикл `do-while` проверяет условие **в конце** итерации. Это значит, что тело цикла гарантированно выполнится **как минимум один раз**.

```solidity
function doWhileLoopExample() public pure returns (uint) {
    uint count = 0;
    
    do {
        count++;
    } while (count < 0); // Условие ложно, но цикл выполнится 1 раз
    
    return count; // Вернет 1
}
```

## Применение циклов с массивами
Чаще всего циклы применяются для записи значений в массивы или подсчета суммы/поиска. 
В Solidity рекомендуется по возможности переносить ресурсоемкие циклы (поиск, фильтрацию) на клиентскую сторону (во frontend / JavaScript), а в контракте хранить лишь необходимый минимум.
