# Типы данных в Solidity

Solidity является статически типизированным языком программирования. Это означает, что тип каждой переменной (состояния или локальной) должен быть указан во время компиляции. В Solidity нет концепции `undefined` или `null`.

## Типы значения (Value Types)
Типы значения передаются по значению, то есть при присваивании или передаче в функцию они всегда копируются.

1. **Boolean (Булевый тип)**: `bool`
   Возможные значения: `true` или `false`.
2. **Integer (Целые числа)**:
   - Без знака: от `uint8` до `uint256` (или просто `uint`, что равно `uint256`).
   - Со знаком: от `int8` до `int256`.
3. **Address (Адрес)**: 
   - `address`: Хранит 20-байтовое значение (размер адреса Ethereum).
   - `address payable`: То же самое, но с дополнительными методами `transfer` и `send` для отправки эфира.
4. **Bytes (Фиксированный массив байтов)**: от `bytes1` до `bytes32`. 
   Гораздо дешевле в плане газа, чем массивы динамической длины.

## Ссылочные типы (Reference Types)
Ссылки не копируют значения напрямую, а указывают на область памяти, где хранятся данные. К ним относятся **массивы, строки (string) и структуры (struct)**.
Для ссылочных типов необходимо указывать локацию памяти:
- `memory` (временная память, живет только внутри функции),
- `storage` (постоянная память блокчейна),
- `calldata` (похожа на memory, но только для чтения входящих аргументов).

## Значения по умолчанию
Поскольку в Solidity нет `null`, любая неинициализированная переменная получает «нулевое» значение по умолчанию:
- `bool`: `false`
- `uint` / `int`: `0`
- `address`: `0x0000000000000000000000000000000000000000` (так называемый нулевой адрес)
- `string`: пустая строка `""`
- Массивы фиксированной длины заполняются нулями для каждого элемента.

## Примеры объявления и управления в коде

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract DataTypesExample {
    // --- Value Types ---
    bool public isReady = true;       // По умолчанию было бы false
    uint256 public count = 100;       // По умолчанию было бы 0
    int256 public temperature = -5;
    
    // Адрес (нулевой, если не задан)
    address public owner = 0x5B38Da6a701c568545dCfcB03FcB875f56beddC4;
    
    // --- Reference Types ---
    // Строка - это по сути динамический массив байтов
    string public greeting = "Hello, Blockchain!";
    
    // Массив фиксированной длины
    uint[3] public fixedArray = [1, 2, 3];
    
    // Динамический массив
    uint[] public dynamicArray;
    
    // Структура - пользовательский тип данных
    struct User {
        uint id;
        string name;
        address wallet;
        bool isActive;
    }
    
    // Маппинг (ассоциативный массив / хэш-таблица)
    mapping(uint => User) public users;

    function manipulateData() public {
        // Управление массивом
        dynamicArray.push(10); // Добавляем элемент в конец
        dynamicArray.pop();    // Удаляем последний элемент
        
        // Создание структуры
        User memory newUser = User({
            id: 1,
            name: "Alice",
            wallet: msg.sender,
            isActive: true
        });
        
        // Сохраняем в mapping (копируется из memory в storage)
        users[1] = newUser;
    }
}
```
