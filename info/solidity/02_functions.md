# Функции в Solidity

Функции в Solidity определяют логику и поведение смарт-контрактов. Из-за архитектуры EVM (Ethereum Virtual Machine) функции имеют строгий синтаксис и множество модификаторов.

## Базовый синтаксис
```solidity
function ИмяФункции(тип_аргумента имя_аргумента) <видимость> <модификаторы_состояния> returns(тип_возвращаемого_значения) {
    // Тело функции
}
```

## Модификаторы доступа (Видимость)
В Solidity есть 4 типа видимости функций:
1. `public` — Функция может быть вызвана откуда угодно (как извне контракта пользователями, так и внутри самого контракта).
2. `private` — Функция доступна только внутри того контракта, где она объявлена (недоступна даже для контрактов-наследников).
3. `internal` — Похоже на `private`, но доступно еще и дочерним контрактам (аналог `protected` в ООП).
4. `external` — Функция может быть вызвана **только извне** (другими контрактами или пользователями), но не может быть вызвана внутри самого контракта напрямую. Это экономит газ.

## Модификаторы состояния: view и pure
Каждый вызов функции в блокчейне, который изменяет состояние сети, стоит Газ. Чтобы явно указать компилятору и пользователям, что функция **не изменяет** состояние (а значит, её вызов бесплатен), используются модификаторы `view` и `pure`.

- `view`: Функция может **только читать** переменные состояния контракта, но не может их изменять.
- `pure`: Функция **не может ни читать, ни изменять** переменные состояния блокчейна. Она работает исключительно с локальными переменными и своими аргументами.

*Если функция изменяет состояние (пишет в блокчейн), то модификатор не ставится.*

## Ключевое слово returns
Ключевое слово `returns` (обязательно с буквой `s`) указывается в сигнатуре функции, если функция должна что-то вернуть. При этом необходимо указать типы всех возвращаемых значений (функция может возвращать несколько переменных одновременно).

Для ссылочных типов (строки, массивы, структуры) в возвращаемом значении также нужно указывать `memory`.

## Примеры

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract FunctionsExample {
    uint public multiplier = 10;

    // 1. Обычная функция, изменяющая состояние (запись)
    function setMultiplier(uint _newMultiplier) public {
        multiplier = _newMultiplier;
    }

    // 2. Функция VIEW: Читает состояние (multiplier), но не изменяет его
    function calculate(uint _value) public view returns (uint) {
        return _value * multiplier;
    }

    // 3. Функция PURE: Не читает и не изменяет состояние контракта.
    // Работает только с переданными аргументами _a и _b
    function addNumbers(uint _a, uint _b) public pure returns (uint) {
        return _a + _b;
    }

    // 4. Функция возвращающая несколько значений (Tuple)
    function getMultipleValues() public pure returns (uint, bool, string memory) {
        return (42, true, "Success");
    }
}
```
