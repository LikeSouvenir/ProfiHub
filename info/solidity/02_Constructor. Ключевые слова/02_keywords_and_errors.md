# Ключевые слова и обработка ошибок

Solidity содержит несколько важных ключевых слов, управляющих ходом выполнения программы и обработкой ошибок. Если транзакция завершается ошибкой, все изменения состояния, сделанные в ходе этой транзакции, **откатываются (revert)**, а газ сгорает.

## returns vs return
Оба слова используются для возврата значений, но в разных местах:
- `returns` (с буквой **s**) пишется **в сигнатуре функции**, указывая типы возвращаемых данных.
- `return` пишется **внутри тела функции**, чтобы завершить её и вернуть конкретное значение.

```solidity
//     ↓ returns (сигнатура)
function getSum(uint a, uint b) public pure returns (uint) {
    return a + b; // ← return (тело)
}
```

## break и continue
Эти слова используются внутри циклов (`for`, `while`, `do-while`):
- `break` — немедленно завершает работу всего цикла.
- `continue` — пропускает оставшийся код в текущей итерации и переходит к следующему шагу цикла.

## Обработка ошибок: revert
Ключевое слово `revert` принудительно прерывает выполнение контракта, откатывает все изменения (включая переводы эфира) и возвращает указанную ошибку. Оставшийся газ возвращается отправителю.

```solidity
function buy(uint _amount) public {
    if (_amount == 0) {
        revert("Amount must be greater than zero");
    }
    // логика покупки
}
```

### Кастомные ошибки (Custom Errors)
Начиная с версии Solidity 0.8.4, появились кастомные ошибки. Они намного эффективнее и дешевле по газу, чем текстовые строки в `revert()`, потому что кодируются в 4 байта.

```solidity
// Объявление кастомной ошибки
error InsufficientBalance(uint requested, uint available);

function withdraw(uint _amount, uint _balance) public pure {
    if (_amount > _balance) {
        // Использование кастомной ошибки
        revert InsufficientBalance(_amount, _balance);
    }
}
```

## Вывод ошибки в кодировке Unicode
По умолчанию строковые литералы в Solidity принимают только ASCII-символы. Если вы попытаетесь вернуть текст ошибки на кириллице или с эмодзи (например, `"Ошибка: нет денег ❌"`), компилятор выдаст предупреждение или ошибку. 

Для использования любых символов необходимо добавить префикс `unicode` перед строкой:
```solidity
function pay() public payable {
    if (msg.value < 1 ether) {
        // Ошибка на русском с эмодзи благодаря префиксу unicode
        revert(unicode"❌ Ошибка: недостаточно средств для оплаты!");
    }
}
```
