# Ключевые слова require и modifier

Обеспечение безопасности и проверка условий — одна из главных задач при написании смарт-контрактов. В Solidity для этого чаще всего используют функцию `require` и кастомные модификаторы `modifier`.

## Функция require
`require` — это удобный способ проверить условие. 
Она принимает два аргумента:
1. Условие (которое должно быть `true`).
2. Строка с сообщением об ошибке (опционально).

Если условие ложно, `require` автоматически вызывает `revert`, прерывает транзакцию и откатывает состояние. По сути, `require(условие, "ошибка")` — это элегантная замена для `if (!условие) { revert("ошибка"); }`.

```solidity
function transfer(address _to, uint256 _amount) public {
    // Если баланса недостаточно, транзакция прервется и выдаст ошибку
    require(balance[msg.sender] >= _amount, unicode"Недостаточно средств");
    
    // Если условие выполнилось, продолжаем перевод
    balance[msg.sender] -= _amount;
    balance[_to] += _amount;
}
```

*Существует также `assert()`, но он используется исключительно для выявления внутренних логических ошибок в коде, которые никогда не должны происходить (например, деление на 0).*

## Модификаторы (modifier)
Модификаторы позволяют изменять поведение функций. Их главная задача — вынести повторяющиеся проверки из тела функций (например, проверку прав доступа) в переиспользуемый блок кода.

Модификатор объявляется ключевым словом `modifier`. 
Обязательный элемент внутри модификатора — это `_;` (символ подчеркивания и точка с запятой). Он указывает компилятору, в каком месте модификатора должно быть вставлено тело самой функции.

### Пример: модификатор проверки владельца
Классический пример — ограничение доступа к функциям только для владельца контракта (шаблон Ownable).

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ModifiersExample {
    address public owner;

    constructor() {
        owner = msg.sender; // Владельцем становится тот, кто задеплоил
    }

    // Объявляем модификатор
    modifier onlyOwner() {
        // Проверяем условие
        require(msg.sender == owner, unicode"Доступ запрещен: Вы не владелец!");
        
        // Вставляем тело функции
        _; 
    }

    // Применяем модификатор к функции
    function changeOwner(address _newOwner) public onlyOwner {
        // Этот код выполнится только если require внутри onlyOwner пройдет успешно
        owner = _newOwner;
    }
    
    // Еще одна функция, защищенная тем же модификатором
    function withdrawFunds() public onlyOwner {
        payable(owner).transfer(address(this).balance);
    }
}
```

### Модификаторы с параметрами
Модификаторы могут принимать аргументы, что делает их еще более гибкими:

```solidity
modifier costs(uint _price) {
    require(msg.value >= _price, unicode"Мало эфира для оплаты");
    _;
}

// Функцию можно вызвать, только прикрепив к транзакции >= 100 wei
function buyItem() public payable costs(100) {
    // покупка
}
```
