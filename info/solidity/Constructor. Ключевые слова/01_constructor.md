# Конструктор (Constructor)

Конструктор — это специальная функция, которая автоматически вызывается **только один раз** в момент развертывания (деплоя) смарт-контракта в блокчейн. 

После того как контракт был развернут, код конструктора навсегда становится недоступным для повторного вызова. Конструктор обычно используется для начальной инициализации переменных состояния контракта.

## Пример использования
Чаще всего в конструкторе задают владельца контракта (того, кто его задеплоил), устанавливают начальные значения параметров или настраивают адреса связанных контрактов.

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ConstructorExample {
    // Переменные состояния
    address public owner;
    uint256 public creationTime;
    string public greeting;

    // Конструктор
    // В старых версиях Solidity имя конструктора совпадало с именем контракта,
    // но сейчас используется ключевое слово `constructor`.
    constructor(string memory _initialGreeting) {
        // msg.sender в момент деплоя — это адрес, который отправляет транзакцию создания контракта
        owner = msg.sender;
        
        // block.timestamp — это время (в секундах), когда блок был добыт
        creationTime = block.timestamp;
        
        greeting = _initialGreeting;
    }

    function changeGreeting(string memory _newGreeting) public {
        // Простейшая проверка, что только владелец может менять текст
        if (msg.sender == owner) {
            greeting = _newGreeting;
        }
    }
}
```

В этом примере, чтобы развернуть контракт, вам потребуется передать строку (например, `"Hello, World"`). Если контракт деплоится из Remix, поле для ввода аргумента появится рядом с кнопкой "Deploy".
